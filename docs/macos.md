# Лист для macOS — тестовая сборка

«Лист» запускается локально и открывается в браузере. Запуск и основные конвертации проверены на одном Mac. Для этой сборки компоненты устанавливаются отдельно через Homebrew.

## Как скачать

1. Откройте [релиз для macOS](https://github.com/l1qu1dd/list-converter/releases/tag/v0.1.0-macos-preview.3).
2. В разделе **Assets** нажмите **`list-macos-preview-v0.1.0-macos-preview.3.zip`**. [Прямая ссылка на ZIP](https://github.com/l1qu1dd/list-converter/releases/download/v0.1.0-macos-preview.3/list-macos-preview-v0.1.0-macos-preview.3.zip).
3. Дважды нажмите ZIP в папке «Загрузки». Откройте распакованную папку `list-macos`. В ней лежат `Запустить.command` и этот файл с инструкцией.

## Что устанавливается

Откройте Терминал и выполните `brew --version`. Если команда не найдена, установите Homebrew по официальной инструкции и выполните показанный установщиком шаг **Next steps**, чтобы `brew` был доступен в Терминале. [Установка Homebrew](https://docs.brew.sh/Installation).

Затем выполните в Терминале две команды. Этот шаг нужно пройти один раз, а при обновлении «Листа» ранее установленные компоненты можно использовать снова.

```sh
brew install node ffmpeg-full poppler pandoc tesseract tesseract-lang djvulibre yt-dlp
brew install --cask calibre libreoffice
```

Первая команда ставит Node.js для запуска интерфейса, FFmpeg для медиа, Poppler для обработки PDF, Pandoc для Markdown, Tesseract и языки для OCR, DjVuLibre для DjVu и yt-dlp для YouTube. Вторая команда ставит Calibre для электронных книг и LibreOffice для Word → PDF. Homebrew может дополнительно установить зависимости этих программ.

## Как запустить

Распакуйте ZIP целиком. В Терминале наберите `bash` и пробел, перетащите из Finder файл **`Запустить.command`** в окно Терминала, затем нажмите Enter. Из папки сборки эта же команда выглядит так:

```sh
bash ./Запустить.command
```

При двойном щелчке macOS может заблокировать неподписанный скрипт. Для файла из доверенного источника Apple описывает, как разрешить его запуск в «Системных настройках» → «Конфиденциальность и безопасность». [Инструкция Apple](https://support.apple.com/ru-ru/102445).

Если браузер не откроется автоматически, перейдите на `http://127.0.0.1:8787`. Пока пользуетесь «Листом», оставьте Терминал открытым. Чтобы завершить работу, нажмите **Ctrl+C** в окне Терминала. Вкладку браузера после этого можно закрыть.

## Как скачать видео с YouTube

1. Откройте в «Листе» **«Видео с YouTube»** и вставьте ссылку на отдельное видео.
2. Выберите **MP4** для видео или **MP3** для звука. Для MP4 можно указать максимальное разрешение. Нажмите кнопку добавления задачи в очередь.
3. Когда задача получит статус **«Готово»**, нажмите **«Скачать»**. Файл сохранится туда, куда браузер обычно сохраняет загрузки.

Для YouTube нужен интернет. Если подключение не проходит, раскройте **«Подключение»**. «Напрямую» использует обычный сетевой маршрут, а «Системные настройки» учитывают системный прокси. Выбранный режим запоминается. В зависимости от подключения YouTube может запросить подтверждение или вернуть сетевую ошибку.

Для проверки сборки попробуйте JPG → PNG, MP4 → MP3, DOCX → PDF, PDF → EPUB и OCR со сканом на русском. Если колонки или таблицы в сложной книге сместились, приложите обезличенный пример и укажите модель Mac, версию macOS и выбранные форматы.

## Как удалить

Чтобы удалить сам «Лист», остановите его клавишами **Ctrl+C** и переместите распакованную папку `list-macos` и скачанный ZIP в Корзину.

Программы Homebrew устанавливаются отдельно. Посмотрите, что установлено, командой `brew list --formula` для пакетов и `brew list --cask` для приложений. Если все компоненты из списка ниже были установлены только для «Листа», сначала посмотрите, что Homebrew собирается удалить:

```sh
brew uninstall --dry-run --cask calibre libreoffice
brew uninstall --dry-run --formula yt-dlp djvulibre tesseract-lang tesseract pandoc poppler ffmpeg-full node
```

Уберите из команд всё, что было установлено раньше или нужно другим программам. Когда список подходит, повторите команды без `--dry-run`. После этого `brew autoremove --dry-run` покажет, остались ли зависимости, которые больше никому не нужны. Сам Homebrew можно оставить. [Справка Homebrew](https://docs.brew.sh/Manpage).
